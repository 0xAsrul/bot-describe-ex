# Describe Your Ex in One Word

An ex, summed up in exactly one word: **Unsubscribe**.

An ex is a newsletter you never signed up for, kept arriving anyway,
and finally — gloriously — you hit unsubscribe.

## Run it

```sh
python3 main.py
```

This writes the single word to `/output/entry.txt` (creating the
directory if needed) and prints it. Deterministic: the same word,
every run. Python 3.13 standard library only.
